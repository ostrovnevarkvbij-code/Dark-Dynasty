Программирование

Dark Arbitr создан на Python с использованием библиотеки lolka.py

main.py 
import lolka as discord
from lolka.ext import commands

bot = commands.Bot(command_prefix="!", intents=discord.Intents.all())

@bot.event
async def on_ready():
    print(f"✅ Бот онлайн: {bot.user}")

bot.run("TOKEN")
